# Avalon Game Making Tool Kit

Free tools for young game creators, made by Avalon Partner and Captain Amado. Each tool is a single HTML file. There is no account, no sign-up and no network: nothing is sent anywhere, and every tool works offline.

The kit is free and source available. The same tools are also on [avalonpartner.com/tools](https://avalonpartner.com/tools).

## The tools

### Plan and design

- [Game Balance & Economy Simulator](tools/game-balance-economy-simulator.html): test rewards, prices, XP, drops, crafting and combat before players do.
- [Level & Quest Flow Designer](tools/level-quest-flow-designer.html): map levels and quests, then check that every path can be finished.
- [Game Feel Sandbox](tools/game-feel-sandbox.html): play small demos, change one setting at a time, and save what feels right.
- [Multiplayer Session Planner](tools/multiplayer-session-planner.html): plan what every player does when they wait, play, join late, leave or come back.
- [Interface Accessibility Workshop](tools/interface-accessibility-workshop.html): make game screens easy to read and use for everyone.

### Build and ship

- [Roblox Game Creator Guide](tools/roblox-game-creator-guide.html): plan a Roblox game step by step, track tasks and budget, and get ready to launch.
- [Asset Brief & Handoff Builder](tools/asset-brief-handoff-builder.html): write clear briefs for art, sound and models, and share them with your team.
- [Localization & Game Text Workspace](tools/localization-game-text-workspace.html): get your game text ready for players who speak other languages.
- [Playtest & Feedback Lab](tools/playtest-feedback-lab.html): plan a playtest, take notes while people play, and pick what to change next.

### Grow and protect

- [Creator Marketing Toolkit](tools/creator-marketing-toolkit.html): find resources, make a promo plan, create your materials, and track what happens.
- [Creator Rights Library](tools/creator-rights-library.html): find free stories, music and art you can use, and check the rights before you do.

## How to use

1. Download or clone this repository.
2. Open `index.html` in your browser and pick a tool, or open any file in `tools/` directly.
3. Work in the tool. It saves to your browser as you go.
4. Click **Save project file** to download a backup of your work. Open it again later with **Open project file**.

Browser saving is handy but not safe on its own. Browsers can erase it, and it can act differently when you open a file straight from your computer instead of from a website. The project file you save is your real backup. Project files use one shared format, so one file can move between tools.
