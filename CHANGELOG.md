# Changelog

## 2026-11: first public release

- Added `index.html`, a start page that lists all 11 tools.
- All tools now use the AmadOpenSource License 1.0 and share one page title style.
- Every tool has a strict Content Security Policy: no network requests, no outside scripts, fonts or images.
- Darker step numbers and labels so small text meets 4.5:1 contrast.
- Game Balance & Economy Simulator: page labels now match the menu numbers and names.
- Multiplayer Session Planner: page labels now match the menu numbers; the "save a copy first" hint only shows when that button does.
- Game Feel Sandbox: opening saved work no longer asks "Leave site?" when nothing changed.
- Asset Brief & Handoff Builder: the save status names the right button on the Project info page.
- Creator Rights Library: exported reports now credit Creator Rights Library.
- Creator Marketing Toolkit: uses its own name everywhere, including calendar exports.
- Roblox Game Creator Guide: removed the built-in copy of version 1 (the file is about 400 KB smaller); the empty tool download is now named `roblox-game-creator-guide.html`.
- Removed internal test logs from help pages and guides.

## 2026-10-21: tool releases

- Asset Brief & Handoff Builder 1.0: 7 asset types, 4 example briefs, change warnings for linked assets, budgets, file previews, 3 ways to share, spreadsheet export and printing.
- Game Balance & Economy Simulator 1.0: exact decimal math for rewards and prices, hard-guarantee drop odds, shared crafting inventory, combat timing and printable reports.
- Game Feel Sandbox 1.0: five playable demos, 19 settings, A/B comparisons, four presets, a guided exercise, comparison notes and exports. Physics uses a fixed 1/120 second step.
- Interface Accessibility Workshop 1.0: screen and flow worksheets, color checks, palette review, layout previews, input matrix, reading order, issue tracking and reports.
- Level & Quest Flow Designer 1.0: a seven-step workflow, visual map and list views, items and flags, AND/OR rules, checkpoints, a test-play walkthrough, problem search and pacing.
- Localization & Game Text Workspace 1.0: game text, word guide, fit test, ready check and Roblox file export.
- Multiplayer Session Planner 1.0: three examples, eleven scenario cards, player timelines, decisions, playtest checklist and reports.
- Playtest & Feedback Lab 1.0: test plans, sessions, notes, findings, suggested changes and before/after comparisons.
- Creator Marketing Toolkit 2.0: shared project files, player notes, game features, playtest notes, promo plans, five helpers and result tracking.
- Creator Rights Library 2026.10.21: project works with exact asset records, evidence, credits, review questions and evidence packets, next to the reference catalog.
- Roblox Game Creator Guide 2.0: feature and time planning, milestones, launch checks, look-backs, and notes from other tools.

## Known limits

The tools have mainly been checked in Chromium-based desktop browsers. They have not been checked on physical phones, tablets or controllers, in Safari or Firefox, with a screen reader, or inside Roblox Studio or another engine.
